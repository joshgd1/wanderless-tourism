# Demo Screenshots

This directory contains screenshots for offline demo presentation.

If Flutter fails to run locally, these screenshots can be used to walk through the demo flow.

Recommended screenshots to capture:

1. Landing page / product purpose
2. Tourist onboarding / preferences
3. Guide recommendation list
4. Match explanation panel
5. Safety/trust indicator
6. Booking simulation
7. Backend test result

Screenshot naming convention:

- `01-landing.png`
- `02-onboarding.png`
- `03-guide-list.png`
- `04-match-explanation.png`
- `05-safety-indicator.png`
- `06-booking-simulation.png`
- `07-backend-tests.png`
